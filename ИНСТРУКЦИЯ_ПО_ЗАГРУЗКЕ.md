# Инструкция по загрузке сайта на хостинг REG.RU

## 📦 Готовые файлы для загрузки

Файл для загрузки: **khasaut-tour-build.zip**

## 🚀 Пошаговая инструкция

### 1. Войдите в панель управления REG.RU
- Перейдите на сайт https://www.reg.ru
- Войдите в личный кабинет
- Выберите ваш домен/хостинг

### 2. Откройте файловый менеджер
- В панели управления найдите раздел "Файловый менеджер" или "FTP"
- Перейдите в корневую директорию сайта (обычно это `public_html` или `www`)

### 3. Загрузите файлы
**Вариант А: Через веб-интерфейс**
- Распакуйте архив `khasaut-tour-build.zip` на вашем компьютере
- Загрузите ВСЕ файлы и папки из распакованной папки в корневую директорию сайта

**Вариант Б: Через архив (если поддерживается)**
- Загрузите файл `khasaut-tour-build.zip` в корневую директорию
- Распакуйте архив прямо на сервере (если есть такая функция)
- Удалите архив после распаковки

### 4. Проверьте структуру файлов
После загрузки в корневой директории должны быть:
```
public_html/
├── index.html
├── 404.html
├── sitemap.xml
├── robots.txt
├── assets/
│   ├── (множество файлов изображений и стилей)
├── about/
├── aktoprak/
├── arkhyz/
├── (другие папки маршрутов)
└── .vite/
```

### 5. Настройте .htaccess (для Apache)
Создайте файл `.htaccess` в корневой директории со следующим содержимым:

```apache
# Enable Rewrite Engine
RewriteEngine On

# Redirect all requests to index.html for client-side routing
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule ^(.*)$ /index.html [L,QSA]

# Enable Gzip compression
<IfModule mod_deflate.c>
    AddOutputFilterByType DEFLATE text/html text/plain text/xml text/css text/javascript application/javascript application/json
</IfModule>

# Set cache headers
<IfModule mod_expires.c>
    ExpiresActive On
    ExpiresByType image/jpg "access plus 1 year"
    ExpiresByType image/jpeg "access plus 1 year"
    ExpiresByType image/gif "access plus 1 year"
    ExpiresByType image/png "access plus 1 year"
    ExpiresByType image/webp "access plus 1 year"
    ExpiresByType image/svg+xml "access plus 1 year"
    ExpiresByType text/css "access plus 1 month"
    ExpiresByType application/javascript "access plus 1 month"
    ExpiresByType text/html "access plus 0 seconds"
</IfModule>
```

### 6. Проверьте работу сайта
- Откройте ваш домен в браузере
- Проверьте основные страницы:
  - Главная страница
  - Страница "О нас" (about)
  - Страницы экскурсий
  - Страница контактов (contact)

## 🔧 Технические детали

- **Сайт собран**: статический HTML/CSS/JS
- **Технология**: React + Vite
- **Предрендеринг**: все страницы предрендерены для SEO
- **Размер сборки**: ~35 МБ (в основном изображения)
- **Домен в коде**: https://khasaut-kmv.ru

## 📝 Важные замечания

1. **Убедитесь**, что файл `index.html` находится в корневой директории сайта
2. Все пути к файлам относительные, поэтому сайт должен работать сразу после загрузки
3. Если используете поддомен, измените canonical URL в коде перед новой сборкой
4. Файлы в папке `assets/` критически важны - не удаляйте их

## 🆘 Возможные проблемы

**Проблема**: Страницы не открываются (404 ошибка)
**Решение**: Проверьте настройки `.htaccess` или конфигурацию веб-сервера

**Проблема**: Изображения не загружаются
**Решение**: Убедитесь, что папка `assets/` загружена полностью

**Проблема**: Сайт отображается без стилей
**Решение**: Проверьте, что файлы CSS из папки `assets/` загружены корректно
