# Khasaut Tour

Premium editorial travel page for Khasaut Tour, built as a standalone React + TypeScript + Vite project.

## Commands

```bash
npm install
npm run dev
npm run typecheck
npm run lint
npm run build
```

The supplied archive and visual references live under `design-reference/khasaut/`. Visual QA artifacts are written to `artifacts/visual-check/` by `node scripts/visual-check.mjs`.
